1. RECORD THE DEMONSTRATION

Wait for the Recording indicator.

Select H5 and paste these six example questions:

No follow-up needed.

2. EXPLAIN THE REASONING (send in Copilot while recording)

The columns I added demonstrate a weekly order review. Open units must be the live table formula =[@Ordered]-[@Shipped]-[@Cancelled]. A cancelled unit is no longer owed: zero open units means no follow-up, even when Shipped is less than Ordered. Do not hide negative balances; ask for reconciliation. Review questions must follow the current Context, not memorized customer names. A planned split delivery is not automatically a failure. Without due dates, do not label orders late. If context is missing, say it is not documented and ask a neutral question. Preserve all source values and the Excel table with filter buttons. Keep the white background, use Arial 11, red #CF3338 headings and charcoal #1F2120 table headers with white text. Before saving, explain which parts belong in deterministic formulas or automation and which need judgment; do not edit the sheet yet. When drafting this new skill, name it net-order-review.

3. STOP AND REVIEW
Click Stop. Read Show details for each file. Save only after checking the formulas, source preservation and question rules. Note the actual skill name that Excel gives you; our test used net-order-review.

4. CHANGE ONE ORDER
In Orders, change D8 from 0 to 60 and F8 from blank to Complete.
Do not edit the existing Review question. Notice that G8 changes to 0 but the old question remains until you rerun the skill.
Start a new Copilot chat using the + at the top of the pane. Replace the skill name below if your recording uses a different name.

@net-order-review Review tblOrders on Orders using the current values. Run the saved skill, including its bundled builder, and refresh the Review question column. Preserve the source values. Report the total open units and explain any follow-up that changed.

5. CHECK
